**Database MCP server and CLI**

## Why dbmcp?

Other database MCP tools require:
- Cloning the entire repository
- Node.js/npm installed
- Setting database credentials in environment variables

**dbmcp** makes it simple:
- Prebuilt binary — no runtime dependencies
- Store credentials securely on your machine
- Guided **`dbmcp init`** for a new project, or **`dbmcp add`** for a quick connection
- Use the connection ID in your MCP client (or let **init** write agent config files for you)

---

## Easy setup

Get **dbmcp** on your PATH, then run **init** once inside your app repo.

### 1. Install dbmcp

**Linux / macOS**

```bash
curl -fsSL https://raw.githubusercontent.com/f24aalam/dbmcp/master/install.sh | bash
```

Ensure `~/.local/bin` (or `/usr/local/bin`) is on your `PATH`.

**Windows (PowerShell)**

```powershell
irm https://raw.githubusercontent.com/f24aalam/dbmcp/master/install.ps1 | iex
```

### 2. Initialize in your project

```bash
cd /path/to/your/project
dbmcp init
```

You’ll get an interactive wizard that:

1. Asks how to connect: **use an existing saved connection**, **scan the project** for DB env/config, or **add a new connection**.
2. Shows **connection details** for review, then **pings** the database and **saves** the connection (unless you picked an existing one — then it only validates).
3. Optionally **installs MCP config** for coding agents in **this project** (Claude, Cursor, Copilot VS Code / CLI, Codex, OpenCode).

After **init**, use **`dbmcp list`** to see connection IDs, or open the generated agent config files in your repo.

> **Note:** Project-local MCP entries generated by **init** use the command name **`godbmcp`** in JSON/TOML. If your binary is installed as **`dbmcp`**, add a symlink or rename, or edit the generated files to match your install.

## `dbmcp init`

| | |
|--|--|
| **Purpose** | Set up dbmcp for the **current directory** as a project: discover or define a DB connection, validate it, and optionally merge MCP server snippets into agent config files. |
| **When to use** | First time you wire a repo to dbmcp, or when you want scan-based discovery + one-shot MCP file updates. |

**Modes**

- **Use existing connections** — pick a connection already stored in dbmcp; no re-save, only ping.
- **Scan this project** — looks for database URLs / env-style config in the tree; pick a candidate or fall back to manual entry.
- **Add new connection** — minimal prompts (name, type, URL or path).

**After connection works**

- Confirm **ping and save** (new connections are written to secure storage).
- **Install MCP config?** — if **Yes**, choose which agents get updated; files are **merged** (existing unrelated entries are kept).
- **No** skips agent selection entirely.

Run **`dbmcp init`** from the project root you want configs scoped to.

## Installation (reference)

Same commands as in [Easy setup](#easy-setup) — repeated here for copy/paste without the init steps.

### Linux/macOS

```bash
curl -fsSL https://raw.githubusercontent.com/f24aalam/dbmcp/master/install.sh | bash
```

### Windows (PowerShell)

```powershell
irm https://raw.githubusercontent.com/f24aalam/dbmcp/master/install.ps1 | iex
```

### Uninstallation

#### Linux/macOS

```bash
rm ~/.local/bin/dbmcp
# or if installed in /usr/local/bin
sudo rm /usr/local/bin/dbmcp
```

#### Windows

```powershell
Remove-Item "$HOME\bin\dbmcp.exe"
```

## Quick Start (manual `add`)

### 1. Add a database connection

```bash
dbmcp add
```

**MySQL example:**

```
user:password@tcp(localhost:3306)/mydb
```

**PostgreSQL example:**

```
postgres://user:password@localhost:5432/mydb
```

**SQLite example:**

```
/home/user/data/mydb.sqlite
```

Follow the prompts to enter your database details.

### 2. List connections

```bash
dbmcp list
```

### 3. Start MCP server

```bash
dbmcp mcp --connection-id <CONNECTION_ID>
```

## Usage in MCP Clients

### Cursor

Add to `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "dbmcp": {
      "command": "dbmcp",
      "args": ["mcp", "--connection-id", "<YOUR_CONNECTION_ID>"]
    }
  }
}
```

### OpenCode

Add to your OpenCode MCP settings with the same command format.

## Commands

| Command | Description |
|---------|-------------|
| `dbmcp init` | Guided project setup: connection (existing / scan / new), validate, optional per-agent MCP config in this repo |
| `dbmcp add` | Add a new database connection |
| `dbmcp list` | List all saved connections |
| `dbmcp mcp` | Start the MCP server |
| `dbmcp completion` | Generate shell autocompletion |
